# Varlink

[![](https://vsmarketplacebadges.dev/version/bachorp.varlink.svg?style=flat-square)](https://marketplace.visualstudio.com/items?itemName=bachorp.varlink)
[![](https://img.shields.io/open-vsx/v/bachorp/varlink?style=flat-square&label=Open%20VSX%20Registry)](https://open-vsx.org/extension/bachorp/varlink)

Varlink language support.

## Features

- Icon
- Syntax Highlighting
- Integration with [`varlink-language-server`](https://github.com/bachorp/varlink-language-server)

## Usage

Installing the language server from source using `git` and `cargo`:

```sh
git clone https://github.com/bachorp/varlink-language-server.git
cargo install --path varlink-language-server
```

The language server binary to be used can be specified in the extension's settings.
