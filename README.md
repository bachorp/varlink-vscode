# Varlink

[![](https://img.shields.io/visual-studio-marketplace/v/bachorp.varlink?style=flat-square)](https://marketplace.visualstudio.com/items?itemName=bachorp.varlink)
[![](https://img.shields.io/open-vsx/v/bachorp/varlink?style=flat-square)](https://open-vsx.org/extension/bachorp/varlink)

Varlink language support.

## Features

- Icon
- Syntax Highlighting
- Integration with [`varlink-language-server`](https://github.com/bachorp/varlink-language-server)

## Usage

Installing the language server from source using `git` and `cargo`:

```sh
git clone https://github.com/bachorp/varlink-language-server.git
cargo install --path varlink-language-server
```
